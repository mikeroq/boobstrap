Interactivity

Vue 3 integration

The official adapter returns reactive state and prop objects for your own semantic markup. It never initializes the vanilla controller layer on Vue-owned DOM.

Install

Terminal · Vue packages
npm install @boobstrap/boobstrap @boobstrap/vue vue

Compose a collapse

Consumer-owned markup

The composable supplies state, events, IDs, and ARIA props; your template chooses the elements and classes.

Vue · Collapse composable
<script setup>
import "@boobstrap/boobstrap";
import { useCollapse } from "@boobstrap/vue";

const details = useCollapse({ id: "details" });
</script>

<template>
  <button class="bs-btn" v-bind="details.getTriggerProps()">Details</button>
  <div class="bs-collapse" v-bind="details.getPanelProps()">Progressive content</div>
</template>

Controlled state

Vue · Ref-owned dialog
import { ref } from "vue";
import { useDialog } from "@boobstrap/vue";

const open = ref(false);
const dialog = useDialog({ open, onOpenChange: (next) => { open.value = next; } });

One owner

Do not run initBoobstrap inside the same component subtree. Vue owns state and lifecycle there.

SSR

Composables use Vue IDs and avoid DOM access during setup so server markup hydrates with stable relationships.

Controlled state

Pass plain values for callback-controlled state or refs for direct reactive ownership. Both expose a computed public state.

Composable API
