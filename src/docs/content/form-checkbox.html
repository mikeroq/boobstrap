Checkbox

The .bs-check and .bs-check-input classes style semantic native checkboxes with theme tokens, high-contrast borders, focus rings, and dark mode support.

Basic checkbox

HTML · Basic checkbox
<label class="bs-check">
  <input class="bs-check-input" type="checkbox" name="remember" />
  <span class="bs-check-label">Remember this device</span>
</label>

Valid state

Verification confirmed.
HTML · Valid checkbox
<div class="bs-form-group">
  <label class="bs-check">
    <input class="bs-check-input bs-is-valid" type="checkbox" checked aria-invalid="false" aria-describedby="valid-msg" />
    <span class="bs-check-label">I have verified my backup recovery codes</span>
  </label>
  <span class="bs-form-feedback bs-form-feedback-valid" id="valid-msg">Verification confirmed.</span>
</div>

Invalid state

Set aria-invalid="true" or apply .bs-is-invalid when validation fails. The checkbox highlights with a danger border and focus outline, and .bs-form-feedback-invalid renders the associated error text.

Terms of service *You must accept the terms before creating an account.
HTML · Invalid checkbox
<div class="bs-form-group">
  <fieldset class="bs-check-group">
    <legend class="bs-label">Terms of service <span class="bs-label-required" aria-hidden="true">*</span></legend>
    <label class="bs-check">
      <input
        class="bs-check-input"
        type="checkbox"
        name="terms"
        aria-invalid="true"
        aria-describedby="terms-error"
        required
      />
      <span class="bs-check-label">I agree to the terms of service and privacy policy</span>
    </label>
    <span class="bs-form-feedback bs-form-feedback-invalid" id="terms-error">
      You must accept the terms before creating an account.
    </span>
  </fieldset>
</div>

Accessible grouping

Wrap related checkbox collections in <fieldset class="bs-check-group"> and label the set using <legend class="bs-label">.

Help and error text

Pair auxiliary messages using aria-describedby pointing to the id of the helper text or error message.

Indeterminate state

Set input.indeterminate = true in JavaScript for parent checkboxes that represent partially selected child groups.

Checkbox API

.bs-check, .bs-check-input, .bs-check-label, .bs-check-description, .bs-check-group, .bs-check-inline, .bs-is-valid, .bs-is-invalid, .bs-form-feedback-valid, and .bs-form-feedback-invalid.
