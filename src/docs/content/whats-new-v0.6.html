What's new in v0.6

A major API completeness and consistency release. Boobstrap now exposes the full responsive grid, the complete spacing grammar, layout utilities, semantic variants for alert and badge, a destructive button, structural design tokens, per-component customization hooks, RTL coverage, and a new IntersectionObserver-based scrollspy controller.

Current release

A predictable, complete public framework contract

Version 0.6 makes Boobstrap's CSS-first public surface complete and consistent. Existing v0.5 selectors and behavior remain available, while the release fills in responsive grid coverage, the spacing grammar, the layout utility surface, semantic color variants, a destructive button treatment, RTL correctness, a11y resilience, and a new scrollspy controller.

Available now: install @boobstrap/boobstrap@0.6.0 from npm or use the version-pinned CDN URL in the installation guide. Official Alpine, React, and Vue adapters are published at the same version.

Responsive grid completeness

The 12-column grid now spans sm (40rem), md (48rem), lg (64rem), xl (76rem), and 2xl (90rem). Span 1 through 12 is available at every breakpoint, alongside .bs-col-auto, .bs-col-{bp}-start-{n}, and .bs-col-{bp}-offset-{n}. Grid gap axes split into .bs-gap-x-* and .bs-gap-y-*.

HTML · Responsive grid
<div class="bs-grid bs-gap-4">
  <div class="bs-col-12 bs-col-md-6 bs-col-xl-3">Span</div>
  <div class="bs-col-12 bs-col-md-6 bs-col-xl-3">Span</div>
  <div class="bs-col-12 bs-col-md-6 bs-col-xl-3">Span</div>
  <div class="bs-col-12 bs-col-md-6 bs-col-xl-3">Span</div>
</div>

Spacing utility grammar

Margin and padding now expose the complete logical-property vocabulary: m, mt, mb, ms, me, mx, my, p, pt, pb, ps, pe, px, py. All use logical CSS properties (margin-inline, padding-block) so right-to-left layouts flip correctly without authoring effort. Responsive variants exist at md and lg for the frequently used families plus the gap family.

Layout utilities

Display (.bs-inline-grid), position (.bs-static, .bs-absolute, .bs-fixed, .bs-sticky), overflow (.bs-overflow-auto, .bs-overflow-x-auto, .bs-overflow-y-auto), flex helpers (.bs-grow, .bs-grow-0, .bs-shrink, .bs-shrink-0, .bs-justify-around, .bs-justify-evenly, .bs-self-start, .bs-self-end, .bs-self-stretch), sizing (.bs-min-w-0, .bs-min-h-screen, .bs-h-screen), text (.bs-truncate, .bs-whitespace-nowrap, .bs-break-words), and media fit (.bs-aspect-square, .bs-aspect-video, .bs-object-cover, .bs-object-contain) all now ship.

Semantic component variants

.bs-alert and .bs-badge now expose the full semantic palette: primary, info, success, warning, danger. .bs-btn-danger ships as the framework's destructive button treatment. All three pull colors from the corresponding --bs-color-* tokens via color-mix(), never from hard-coded RGB values.

HTML · Semantic alert and button variants
<div class="bs-alert bs-alert-danger" role="alert">
  <strong class="bs-alert-title">Destructive action</strong>
  This operation cannot be undone.
</div>
<button class="bs-btn bs-btn-danger" type="button">Delete workspace</button>

Structural tokens and component customization hooks

Ten z-index tokens (--bs-z-dropdown through --bs-z-dialog), four control-size tokens (--bs-control-size-sm/md/lg/xl), three button-size tokens (--bs-btn-size-sm/md/lg), and an overlay-backdrop token (--bs-overlay-backdrop) replace raw magic numbers. Component-local customization hooks let applications tune one component family without touching the global scale: --bs-btn-*, --bs-card-*, --bs-dialog-*, --bs-control-*, --bs-banner-*, --bs-toast-*, --bs-sidebar-*.

RTL coverage and forced-colors

Logical-property audit of every component, fourteen new RTL visual fixtures, and forced-colors coverage for checkbox, switch, range, select, primary button, and alert. The framework now passes an RTL viewport Playwright suite and reports a recognizable OS shape under Windows High Contrast.

Adapter parity

Five new controllers reach universal Alpine, React, and Vue adapter coverage: Banner, Sidebar, InputMask, Otp, and Password. A new IntersectionObserver-based Scrollspy controller also ships with the same three-adapter guarantee.

Minified distribution

Boobstrap now ships a minified CSS bundle at @boobstrap/boobstrap/min.css with raw / gzip / brotli size budgets enforced by CI. The unminified dist/boobstrap.css remains the default import for backward compatibility.

Breaking change

Heads up: aria-invalid="false" no longer styles fields as valid on .bs-input, .bs-select, or .bs-textarea. Most accessibility-first form frameworks set aria-invalid="false" by default, so the previous behavior styled every untouched input with a green border. Consumers who relied on the implicit green border must now apply .bs-is-valid explicitly. See Inputs for the migration pattern.

Release confidence

The release gate now covers RTL behavior, accessibility resilience (320px viewport, 200% zoom, forced colors, focus, keyboard, reduced motion), and the new minified artifact, in addition to strict TypeScript fixtures, adapter conformance, distributable token verification, and Playwright visual baselines.

Update validation markup

If application code relied on aria-invalid="false" to style valid fields, add .bs-is-valid explicitly to those fields after validation passes.

Use the breakpoint tokens

Replace hard-coded media-query rem values with the new --bs-breakpoint-{sm,md,lg,xl,2xl} tokens when authoring custom responsive styles.

Adopt the minified bundle in production

Switch your production import to @boobstrap/boobstrap/min.css when network weight matters; the unminified default remains unchanged.

Use semantic variants for state

Replace any application-side style="color: var(--bs-color-danger)" overrides with .bs-alert-danger, .bs-badge-warning, or .bs-btn-danger so theme switching just works.
