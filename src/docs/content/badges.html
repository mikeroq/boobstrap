Badges

Badges are compact status and metadata labels. Use the base class alone for a neutral badge or add the primary modifier.

Draft New release Loved
HTML
<span class="bs-badge bs-badge-primary">New release</span>

Default and primary badges

Use the default badge for neutral metadata and the primary variant when a label needs brand emphasis.

Badges in context

Place badges beside a clear label or heading; the badge should supplement the surrounding text rather than replace it.

API deployment

3 changes

Ready for review by the infrastructure team.

Meaning

Use short nouns, counts, or states. A badge is supporting metadata, not a substitute for an actionable control.

Context

Make the surrounding sentence or heading understandable without depending on the badge color.

Semantics

A plain <span> is appropriate for static metadata. Use a button or link only when the label itself is interactive.
