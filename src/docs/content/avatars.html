Avatars

Avatars are supporting identity cues. Always keep the person or entity name available in adjacent text or an accessible label.

Images and fallbacks

Place an <img> and a fallback inside .bs-avatar. Both occupy the same grid area so the image renders on top and fallback initials or icons display seamlessly if the image is unavailable or loading.

ALALAda Lovelace
HTML · Image and fallbacks
<!-- Combined image and fallback -->
<span class="bs-avatar">
  <img class="bs-avatar-image" src="/images/ada.jpg" alt="" onerror="this.remove()" />
  <span class="bs-avatar-fallback" aria-hidden="true">AL</span>
</span>

<!-- Initials fallback -->
<span class="bs-avatar">
  <span class="bs-avatar-fallback" aria-hidden="true">AL</span>
</span>

<!-- Icon fallback -->
<span class="bs-avatar">
  <span class="bs-avatar-icon" aria-hidden="true"><i data-lucide="user" class="bs-icon"></i></span>
</span>
<span>Ada Lovelace</span>

Badges and icon overlays

Overlay a notification count badge or role icon on the top or bottom corner using .bs-avatar-badge or .bs-avatar-badge-bottom.

AL3AI
HTML · Badges and icon overlays
<!-- Notification badge -->
<span class="bs-avatar">
  <span class="bs-avatar-fallback">AL</span>
  <span class="bs-avatar-badge" aria-label="3 notifications">3</span>
</span>

<!-- Verified icon badge (bottom right) -->
<span class="bs-avatar bs-avatar-lg">
  <img class="bs-avatar-image" src="/favicon.svg" alt="" />
  <span class="bs-avatar-badge bs-avatar-badge-bottom" aria-label="Verified user">
    <i data-lucide="check" class="bs-icon"></i>
  </span>
</span>

<!-- Role / bot badge -->
<span class="bs-avatar bs-avatar-lg">
  <span class="bs-avatar-icon"><i data-lucide="bot" class="bs-icon"></i></span>
  <span class="bs-avatar-badge" aria-label="AI assistant">AI</span>
</span>

Decorative image

Use an empty image alt when the visible name already identifies the person.

Status text

Do not rely on the status dot’s color alone. Add a label or adjacent status text.

Group label

Name the group and expose the actual members elsewhere when the stack summarizes collaboration.

Avatar API

.bs-avatar, .bs-avatar-sm, .bs-avatar-lg, .bs-avatar-xl, .bs-avatar-image, .bs-avatar-fallback, .bs-avatar-icon, .bs-avatar-status, .bs-avatar-status-warning, .bs-avatar-status-danger, .bs-avatar-badge, .bs-avatar-badge-bottom, .bs-avatar-group, and .bs-avatar-excess compose the family.
