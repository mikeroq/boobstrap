Alerts

Alerts communicate inline feedback. Pair .bs-alert with a state modifier and use .bs-alert-title for a clear lead-in.

Contextual variants

PrimaryHighlighted guidance or important feature notice.
InformationScheduled maintenance will begin at 02:00 UTC.
SuccessYour configuration changes were published successfully.
WarningThis environment contains uncommitted migrations.
DangerUnable to connect to the database cluster.
Neutral noteThe base alert works without any color modifier.

<div class="bs-alert bs-alert-primary" role="status">

</div>

Structure

Combine an optional decorative icon with a text wrapper. Put the short summary in .bs-alert-title before the supporting message.

Class map

.bs-alert is neutral. Add .bs-alert-primary, .bs-alert-info, .bs-alert-success, .bs-alert-warning, or .bs-alert-danger to match the context.

Accessibility

Use role="status" for dynamic, non-urgent feedback and role="alert" sparingly for urgent errors. Never rely on color alone.

Informational alert

Use status for helpful information that should not interrupt the user.

Deployment queuedYour change will start after the active build completes.
HTML · Informational status
<div class="bs-alert bs-alert-primary" role="status">
  <span><strong class="bs-alert-title">Deployment queued</strong>Your change will start after the active build completes.</span>
</div>

Success alert

Pair the contextual surface with explicit text so success is not communicated by color alone.

Changes savedYour notification settings are up to date.
HTML · Success status
<div class="bs-alert bs-alert-success" role="status">
  <span><strong class="bs-alert-title">Changes saved</strong>Your notification settings are up to date.</span>
</div>

Alert API

The visual variant describes emphasis; the ARIA role describes announcement behavior. Choose each independently.

ClassPurpose
.bs-alertNeutral alert layout, spacing, border, and surface.
.bs-alert-titleHigh-contrast summary placed before supporting copy.
.bs-alert-primaryBrand-highlighted guidance or informational emphasis.
.bs-alert-infoInformational notice or operational context.
.bs-alert-successSuccessful completion or positive confirmation feedback.
.bs-alert-warningCautionary notice or non-blocking issue.
.bs-alert-dangerCritical failure or blocking error condition.
