Command palette architecture

The command palette is an accessible dialog with search input, group headers, icons, keyboard shortcuts, and live filtering.

Navigation
Actions
HTML · Command palette
<button class="bs-btn bs-btn-secondary" type="button" data-bs-toggle="command-palette" data-bs-target="#my-command-palette">
  <kbd class="bs-badge bs-badge-subtle">Cmd+K</kbd> Open command palette
</button>

<dialog class="bs-dialog bs-command-palette" id="my-command-palette" aria-label="Command palette">
  <div class="bs-command-palette-header">
    <input class="bs-input bs-command-palette-input" type="search" placeholder="Type a command or search..." />
  </div>
  <div class="bs-command-palette-list" role="listbox">
    <div class="bs-command-palette-group">
      <div class="bs-command-palette-group-title">Navigation</div>
      <button class="bs-command-palette-item" type="button" role="option">
        <span class="bs-command-palette-item-label">Documentation</span>
      </button>
    </div>
  </div>
</dialog>

Framework adapters

Available as initCommandPalettes() in vanilla JS, x-data="commandPalette()" in Alpine, useCommandPalette() in React and Vue, and createCommandPalette() in Svelte.
