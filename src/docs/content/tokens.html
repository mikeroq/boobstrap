Design tokens

All framework decisions are exposed as CSS custom properties. Color tokens may be remapped by a theme; typography, spacing, radius, elevation, container, and motion tokens are shared. Compare every palette and resolved color value in the complete theme color reference.

Override semantic tokens

Theme a subtree by redefining public semantic variables on its boundary. Components inside consume the new values automatically.

Customized

Semantic override

The button and badge inherit the local primary color.

HTML · Scoped token override
<section class="campaign" style="--bs-color-primary: #7c3aed; --bs-color-primary-hover: #8b5cf6;">
  <span class="bs-badge bs-badge-primary">Customized</span>
  <button class="bs-btn bs-btn-primary" type="button">Continue</button>
</section>

Semantic first

Prefer --bs-color-primary and other semantic variables over raw palette tokens when customizing components.

Scope

Override on :root for the whole application, a theme attribute for one palette, or a component ancestor for a local treatment.

Fallbacks

Keep every required state token—default, hover, active, focus, border, and text—legible in both light and dark contexts.

Use tokens in build tools and design tools

Boobstrap v0.5 generates JavaScript, JSON, and TypeScript declarations from the same CSS source used by the framework. Import the ES module when application or build code needs named tokens and modes collections; import JSON when a tool consumes data without executing a module.

JavaScript · Token exports
import tokenArtifact, { modes, tokens } from "@boobstrap/boobstrap/tokens";
import tokenJson from "@boobstrap/boobstrap/tokens.json" with { type: "json" };

const primary = tokens.color.primary.$value;
const lightOverrides = modes['[data-bs-theme="light"]'];

console.log(tokenArtifact.tokens === tokens); // true
console.log(tokenJson.tokens.color.primary.$value);

Token artifact contract

ExportShapeUse it for
default{ tokens, modes }Passing the complete source-derived artifact to another tool.
tokensGrouped token records with $value and $extensionsReading base values and their originating --bs-* CSS variable names.
modesCSS-selector keys mapped to variable overridesInspecting light mode, palette, and radius remaps without resolving CSS in a browser.
tokens.json$schema and $description metadata plus tokens and modesDesign-token pipelines, documentation generators, and non-JavaScript consumers that need the complete generated envelope.
Source of truth: keep styling in CSS custom properties. The code artifacts are generated interoperability data and must not be edited. Exact var() aliases become DTCG-style references such as {brand.500}; CSS-native expressions such as gradients, shadows, clamp(), and font stacks remain lossless strings. See TypeScript for the exported declaration shape.
