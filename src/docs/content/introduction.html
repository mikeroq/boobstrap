What ships in the framework

CSS foundations

A small reset, semantic theme tokens with code exports, responsive containers, a 12-column grid, typography, and composable utilities.

UI components

Buttons, cards, badges, accordions, skeletons, alerts, banners, form controls, code windows, and interaction presentation classes.

Optional behavior

Typed, dependency-free controllers plus official Alpine.js, React, and Vue adapters for stateful components.

Copy-ready docs

Every visual example is paired with source and can be inspected independently in light or dark mode.
