Switch

The .bs-switch modifier turns any .bs-check checkbox into a toggle switch with smooth pill animations and full keyboard accessibility.

Basic switch

HTML · Basic switch
<label class="bs-check bs-switch">
  <input class="bs-check-input" type="checkbox" name="airplane_mode" />
  <span class="bs-check-label">Airplane mode</span>
</label>

Invalid state

Apply aria-invalid="true" or .bs-is-invalid when a required switch setting has not been confirmed or accepted. The switch track and focus ring show the danger tone and the error message appears below.

Production migration *You must enable the confirmation toggle before running database migrations.
HTML · Invalid switch
<div class="bs-form-group">
  <fieldset class="bs-check-group">
    <legend class="bs-label">Production migration <span class="bs-label-required" aria-hidden="true">*</span></legend>
    <label class="bs-check bs-switch">
      <input
        class="bs-check-input"
        type="checkbox"
        name="confirm_migration"
        aria-invalid="true"
        aria-describedby="migration-error"
        required
      />
      <span class="bs-check-label">Confirm schema migration on live production cluster</span>
    </label>
    <span class="bs-form-feedback bs-form-feedback-invalid" id="migration-error">
      You must enable the confirmation toggle before running database migrations.
    </span>
  </fieldset>
</div>

Instant settings

Switches represent instant on/off toggles. For multi-field forms submitted via a button, standard checkboxes are often preferred.

Role="switch" support

Add role="switch" to the input element when appropriate for screen reader software to announce the control as a switch.

Switch API

.bs-check, .bs-switch, .bs-check-input, .bs-check-label, .bs-check-description, .bs-check-group, .bs-is-valid, .bs-is-invalid, .bs-form-feedback-valid, and .bs-form-feedback-invalid.
