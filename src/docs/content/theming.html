Theming

Boobstrap themes have four independent axes: color mode, palette, corner shape, and scrollbar presentation. Combine their data attributes on <html> for an application-wide theme or on a component boundary for a scoped preview.

Mode

Mode remaps surfaces, text, borders, controls, shadows, and contrast for dark or light environments.

Palette

Palette remaps the brand scale and every connected semantic accent, including primary states, focus rings, gradients, and brand shadows.

Corners

Small, normal, and large presets remap the complete radius scale, including scrollbar thumbs. rounded aliases normal for compatibility; square sets every corner to zero.

Themed scrollbars

Boobstrap applies theme-aware scrollbars by default, using --bs-scrollbar-thumb, --bs-scrollbar-track, and --bs-scrollbar-size. The themed presentation contains only the track and draggable thumb; browser arrow buttons are hidden. Set data-bs-scrollbars="native" on <html> or a subtree to restore the browser presentation. Inside a native subtree, .bs-scrollbar opts one scroll container back into the themed treatment. The legacy themed value remains compatible but is no longer required.

Scrollbar thumb corners consume --bs-radius-pill, so radius presets apply consistently: data-bs-radius="square" produces square scrollbar thumbs instead of rounded ones.

Reading the values: Solid colors use hex notation. Translucent focus, border, and control values retain their CSS rgb(... / ...%) notation so their alpha channel remains explicit. The complete non-color token inventory is available in Design tokens.

Set a document default

Place all three attributes on the same theme boundary. Omitting an attribute uses its default, but explicit values make application intent easier to audit.

HTML
<html data-bs-theme="light" data-bs-palette="teal" data-bs-radius="square">
  <body>...</body>
</html>

Scope a themed region

Attributes may live on any ancestor, so previews, dashboards, or embedded product areas can use their own combination without changing the surrounding page.

HTML
<section data-bs-theme="dark" data-bs-palette="violet" data-bs-radius="rounded">
  <article class="bs-card bs-card-body">...</article>
</section>

Customize semantic tokens

Override tokens after importing Boobstrap. Define the complete primary state set—including readable foreground and focus treatment—so buttons, forms, alerts, tabs, and badges stay visually coherent.

CSS
[data-product-theme] {
  --bs-color-primary: #6d4aff;
  --bs-color-primary-hover: #8568ff;
  --bs-color-primary-active: #5638d6;
  --bs-color-primary-contrast: #ffffff;
  --bs-color-focus-ring: rgb(109 74 255 / 30%);
  --bs-radius-md: 0.5rem;
}
Keep overrides semantic

Prefer --bs-color-*, --bs-radius-*, --bs-shadow-*, and --bs-gradient-* over component-specific color patches. Re-check text, control, and focus contrast in both modes.

Scope a complete theme to one region

All three attributes inherit through a subtree, which is useful for embedded products, dashboards, and previews with a distinct visual identity.

Persist a mode preference

Mode can change without disturbing the selected palette or corner profile. Apply a stored preference before paint when possible to avoid a visual flash.

JavaScript · Mode toggle
const root = document.documentElement;
const toggle = document.querySelector("[data-theme-toggle]");

toggle.addEventListener("click", () => {
  const next = root.dataset.bsTheme === "light" ? "dark" : "light";
  root.dataset.bsTheme = next;
  localStorage.setItem("theme", next);
});
