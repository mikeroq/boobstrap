Forms

One-time password

The OTP controller accepts one character per field, advances focus, supports full-code paste, handles arrow and Backspace navigation, and synchronizes one submitted value. Pasted characters are filtered by the configured pattern; if a paste contains more valid characters than available fields, the entire paste is rejected without changing the inputs, value, or state.

JavaScript · Initialize and handle completion
import "@boobstrap/boobstrap";
import { initOtps } from "@boobstrap/boobstrap/js/otp";

const [verificationCode] = initOtps(document);

verificationCode.element.addEventListener("bs:otp:complete", (event) => {
  console.log("Complete code:", event.detail.value);
});

Autocomplete: the controller applies autocomplete="one-time-code" to the first field and numeric input mode to every field. Use data-bs-otp-pattern only when the code accepts characters other than digits.

One-Time Password API

OTP classes and data attributes organize segmented verification input boxes with automated focus control and value synchronization.

Class / Data AttributePurpose
.bs-otpFlex container wrapping segmented character input fields and the hidden synchronized value input.
.bs-otp-inputIndividual single-character input box with centered text alignment and focus indicators.
.bs-is-invalidNegative validation state applied to digit fields when code verification fails.
data-bs-otpInitializes the vanilla JavaScript OTP controller on the container.
data-bs-otp-inputMarks an individual digit field as a participant in the OTP controller.
data-bs-otp-valueDesignates the hidden input where the aggregated code string is synchronized for form submission.
data-bs-otp-patternCustom regular expression pattern string for validating acceptable pasted or typed characters.
bs:otp:completeEvent fired on the OTP container when all character fields have been filled.
.bs-form-feedback-invalidError feedback message describing expired or incorrect verification codes.
