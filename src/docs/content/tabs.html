Tabs

Tabs use automatic activation and a roving tabindex. Horizontal lists use Left/Right; vertical lists use Up/Down. Both support Home and End.

Structure

Each tab's aria-controls and panel's aria-labelledby form a two-way relationship.

State

The selected tab gets aria-selected="true"; every inactive panel uses hidden.

Accessibility

Use tabs only when panels are peer views. Preserve meaningful headings inside complex panels.

Pill tabs

Use the pills modifier for a compact view switcher. It changes presentation only; the same tab roles, relationships, and controller behavior still apply.

Initialize and observe tabs

The tabs controller synchronizes selection, panel visibility, roving focus, and change events.

JavaScript · Initialization and events
import { initBoobstrap } from "@boobstrap/boobstrap/js";

const boobstrap = initBoobstrap(document);
const tablist = document.querySelector("[data-bs-tabs]");

tablist.addEventListener("bs:tabs:changed", (event) => {
  console.log("Selected tab", event.detail.tab.id);
});

// Later: boobstrap.destroy();

Tab presentation classes

Presentation modifiers do not change tab semantics or behavior. Apply them to the base tablist and panel classes while keeping every ARIA relationship intact.

ClassPurpose
.bs-tabs-pillsTurns the base tablist into a compact pill-style view switcher.
.bs-tabs-containedConnects the tablist visually to a bordered content surface.
.bs-tab-panel-containedAdds the matching border, surface, radius, and padding to each controlled panel.

JavaScript API

Import Tabs from @boobstrap/boobstrap/js/tabs.

ContractPurpose
activate(tab)Select a tab element and synchronize all controlled panels.
bs:tabs:changeCancelable before-event with previous and next tab/panel detail.
bs:tabs:changedBubbling event after the completed transition.
