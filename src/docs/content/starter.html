Application entry

The starter keeps framework setup explicit and exposes the returned cleanup function for hot reloads or application teardown.

JavaScript · src/main.js
import "@boobstrap/boobstrap/dist/boobstrap.css";
import { initBoobstrap } from "@boobstrap/boobstrap/js";
import "./styles.css";

const boobstrap = initBoobstrap(document);

if (import.meta.hot) {
  import.meta.hot.dispose(() => boobstrap.destroy());
}

Project-level customization

Load overrides after the framework stylesheet and change semantic tokens instead of reaching into component selectors.

CSS · src/styles.css
:root {
  --bs-color-primary: #7c3aed;
  --bs-color-primary-hover: #8b5cf6;
  --bs-container-xl: 72rem;
}

.site-shell {
  min-height: 100vh;
}

Run

Use npm run dev while building and npm run validate before shipping the generated bundle.

Customize

Keep application CSS after the framework import. Prefer semantic tokens and composition utilities for system-wide changes.
