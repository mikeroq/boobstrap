Navigation

Boobstrap provides complementary navigation patterns for application headers, vertical link groups, breadcrumb trails, and previous/next article links. Use the dedicated Sidebar component when navigation becomes an application shell, drawer, or collapsible rail.

Choose a pattern

Use the navbar for a global header, a vertical nav for a short destination list, breadcrumbs for hierarchy, and page navigation for a linear reading sequence. Use Sidebar for an application rail or drawer.

Current state

Add aria-current="page" to the current destination. Do not rely on color or font weight alone to communicate which page is active.

Landmarks

Keep destinations as real links. Give each <nav> a distinct accessible label when the page contains multiple navigation landmarks.

Grouped vertical navigation

Use grouped navigation for persistent sidebars. Mark the current destination with aria-current and indent only true child destinations.

Breadcrumb trail

Breadcrumbs show the current page's position in a hierarchy. Keep the final item as plain text and identify the landmark with an accessible label.

  <a href="/docs/components">Components</a>

</nav>

Behavior layers

Choose exactly one owner for a navbar instance. Every layer uses the same open/closed presentation states and lifecycle event names.

JavaScript · Core controller
import { Navbar } from "@boobstrap/boobstrap/js/navbar";

const navbar = Navbar.getOrCreateInstance(document.querySelector("[data-bs-navbar]"));
navbar.show();
navbar.hide();
HTML · Alpine adapter
<header class="bs-navbar" x-data="bsNavbar">
  <button class="bs-navbar-toggle" x-bind="trigger" aria-controls="menu">Menu</button>
  <div class="bs-navbar-menu" id="menu" x-ref="navbar" x-bind="menu">…</div>
  <button class="bs-navbar-backdrop" x-bind="dismiss" aria-label="Close navigation"></button>
</header>
JSX · React adapter
import { useNavbar } from "@boobstrap/react";

const navbar = useNavbar({ id: "primary-menu" });
return <><button {...navbar.getTriggerProps()}>Menu</button><div className="bs-navbar-menu" {...navbar.getMenuProps()}>…</div><button className="bs-navbar-backdrop" {...navbar.getDismissProps()} /></>;
JavaScript · Vue adapter
import { useNavbar } from "@boobstrap/vue";

const navbar = useNavbar({ id: "primary-menu" });
// Bind navbar.getTriggerProps(), getMenuProps(), and getDismissProps().

Responsive semantics

The core controller applies dialog semantics only below the configured media query and returns the menu to ordinary navigation on desktop.

Selection dismissal

Add data-bs-navbar-close to destinations that should close the mobile menu without restoring focus to the toggle.

One behavior owner

Do not initialize core JavaScript on markup already controlled by Alpine, React, or Vue.

Navigation class API

The navigation presentation remains CSS-first. Add data-bs-navbar to opt a menu into the responsive controller, or use the matching bsNavbar, useNavbar, or useNavbar adapter API when Alpine, React, or Vue owns state.

ClassPurpose
.bs-navbarAligns the brand, navigation, and menu control in a full-width header row.
.bs-navbar-brandStyles the product or site identity link.
.bs-navbar-linkStyles navigation destinations with hover and current-page states.
.bs-navbar-toggleProvides an icon-sized menu control with visible interaction states.
.bs-navbar-menu / .bs-navbar-nav / .bs-navbar-actionsCompose inline desktop navigation and the responsive off-canvas menu.
.bs-navbar-backdrop / .bs-navbar-openProvide mobile dismissal and document scroll locking while the menu is open.
.bs-navCreates a vertical navigation stack with consistent spacing.
.bs-nav-groupGroups related destinations and separates adjacent groups.
.bs-nav-headingStyles a non-interactive label for a navigation group.
.bs-nav-linkStyles a vertical destination and its aria-current state.
.bs-nav-link-subitemIndents a destination that is conceptually nested under another item.
.bs-breadcrumbArranges a compact hierarchy trail with wrapping and muted separators.
.bs-page-navLays out previous and next article links in a responsive pair.
.bs-page-nav-linkCreates a bordered page destination with hover and focus treatment.
.bs-page-nav-contextStyles the short directional label, such as “Previous” or “Next.”
.bs-page-nav-titleStyles the destination page title as the primary link text.
