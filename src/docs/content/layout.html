12-column grid

Use .bs-grid or its alias .bs-row, then assign column spans. Unprefixed columns work at every width; md begins at 48rem and lg at 64rem.

Container

Use one container to establish page gutters and a readable maximum width. Nesting containers usually creates uneven alignment.

Grid

Start with .bs-col-12, then add only the breakpoint spans that materially change the composition.

Source order

Keep the DOM in its meaningful mobile reading order. Layout utilities should not create a visual order that disagrees with reading or focus order.
