Input groups and icons

Attach contextual text, controls, or actions to an input, or place decorative icons inside the control boundary.

Text prefix and suffix

$ USD
HTML · Text prefix and suffix
<div class="bs-form-group">
  <label class="bs-label" for="price">Price</label>
  <div class="bs-input-group">
    <span class="bs-input-group-text" aria-hidden="true">$</span>
    <input
      class="bs-input"
      id="price"
      name="price"
      inputmode="decimal"
      value="49.00"
      aria-describedby="price-currency"
    />
    <span class="bs-input-group-text" id="price-currency">USD</span>
  </div>
</div>

<div class="bs-form-group">
  <label class="bs-label" for="subdomain">
    Custom subdomain <span class="bs-label-required" aria-hidden="true">*</span>
  </label>
  <div class="bs-input-group">
    <input
      class="bs-input"
      id="subdomain"
      name="subdomain"
      value="my invalid site!"
      aria-invalid="true"
      aria-describedby="subdomain-error"
    />
    <span class="bs-input-group-text">.boobstrap.org</span>
  </div>
  <span class="bs-form-feedback bs-form-feedback-invalid" id="subdomain-error">
    Subdomains may only contain lowercase letters, numbers, and hyphens.
  </span>
</div>

Icon responsibility

Decorative icons use aria-hidden="true"; the visible label still names the control. When the icon communicates status, pair it with visible or screen-reader text outside the SVG.

Sizing alignment

Group items naturally inherit control height and baseline alignments from the outer form system.

Input groups API

.bs-input-group, .bs-input-group-text, .bs-input-wrap, .bs-input-icon, .bs-input-icon-start, .bs-input-icon-end, .bs-input-has-icon-start, and .bs-input-has-icon-end.
