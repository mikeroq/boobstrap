Invalid state

Apply aria-invalid="true" or .bs-is-invalid to a required radio group that has not received a valid selection. The radio circles highlight in danger red and display the invalid message.

Storage location *Please select a primary storage region.
HTML · Invalid radio group
<div class="bs-form-group">
  <fieldset class="bs-check-group">
    <legend class="bs-label">Storage location <span class="bs-label-required" aria-hidden="true">*</span></legend>
    <label class="bs-check">
      <input
        class="bs-check-input"
        type="radio"
        name="region"
        value="us"
        aria-invalid="true"
        aria-describedby="region-error"

Shared name attribute

Ensure all radio options within the same group share the exact same name attribute to guarantee mutual exclusivity.

Keyboard navigation

Radio groups support arrow-key navigation out of the box with native browser accessibility.

Radio API

Radio classes style mutually exclusive option sets, alignment, label association, and error feedback.

ClassPurpose
.bs-checkContainer element wrapping radio input, label text, and description.
.bs-check-inputCircular custom radio indicator with inner dot styling on checked state.
.bs-check-labelPrimary label text adjacent to the radio button.
.bs-check-descriptionSupporting explanatory text positioned under the radio label.
.bs-check-groupFieldset container grouping mutually exclusive radio options vertically.
.bs-check-inlineHorizontal layout modifier arranging radio controls side by side.
.bs-is-validPositive validation state styling for radio controls.
.bs-is-invalidNegative validation state styling with error border and focus accent.
.bs-form-feedback-validSuccess message text associated with valid group selection.
.bs-form-feedback-invalidError message text describing required or invalid radio choices.
