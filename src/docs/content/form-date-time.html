Date and time inputs

Apply .bs-input to native date and time types to retain platform pickers, locale formatting, validation, and mobile keyboards.

Date input

HTML · Date input
<div class="bs-form-group">
  <label class="bs-label" for="start-date">Start date</label>
  <input class="bs-input" id="start-date" name="start_date" type="date" min="2026-01-01" />
</div>

Invalid date

Deployment date must be set in the future.
HTML · Invalid date input
<div class="bs-form-group">
  <label class="bs-label" for="scheduled-date">
    Scheduled deployment <span class="bs-label-required" aria-hidden="true">*</span>
  </label>
  <input
    class="bs-input"
    id="scheduled-date"
    name="scheduled_date"
    type="date"
    value="2025-01-01"
    aria-invalid="true"
    aria-describedby="date-error"
    required
  />
  <span class="bs-form-feedback bs-form-feedback-invalid" id="date-error">
    Deployment date must be set in the future.
  </span>
</div>
Server handling: native date values submit as date-like strings without a timezone. Treat datetime-local as local wall time and collect a timezone separately when the instant matters.

Date & Time Controls API

Native date and time pickers inherit standard control styling, focus rings, calendar indicators, and validation states.

Class / TypePurpose
.bs-inputApplies standard height, padding, theme background, border, and focus states to date and time controls.
type="date"Native calendar date picker formatted as YYYY-MM-DD.
type="time"Native 12h or 24h time picker with optional minute and second stepping.
type="datetime-local"Combined date and wall-clock time picker without timezone offset.
type="month"Year and month selector formatted as YYYY-MM.
type="week"Year and week-number selector formatted as YYYY-Www.
.bs-form-groupVertical grid layout binding label, date control, helper text, and error messages.
.bs-labelAssociated field label for date and time inputs.
.bs-form-feedback-invalidError message text describing invalid date ranges or missing required choices.
