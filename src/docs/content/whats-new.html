What's new in v0.5

Build richer loading and disclosure experiences, consume framework contracts from typed code and token tools, and rely on the same behavior across every official adapter.

Release preview

A broader public framework contract

Version 0.5 is additive: existing v0.4 selectors and behavior remain available, while the dev preview introduces two component families, code-consumable design tokens, core and Alpine declarations, a Vue adapter, and tighter parity checks across every behavior layer.

Availability: this page documents the framework dev branch used by the hosted dev preview. Until release promotion publishes v0.5, normal package-manager and CDN installation still resolve to the current production version. Do not pin an unpublished v0.5 registry version.

New component primitives

Accordion

Compose collapse panels into single-open or always-open groups, with compact and flush presentation plus vanilla, Alpine, React, and Vue APIs.

Skeletons

Reserve text, avatar, media, and custom content shapes using CSS-only pulse or wave placeholders that stop under reduced motion.

Types and token exports

The package now exposes declarations beside core JavaScript entry points and the Alpine adapter, complementing the React and Vue declarations. The same build also derives JSON, ES module, and TypeScript token artifacts from the framework's runtime CSS variables.

TypeScript · New typed surfaces
import { Accordion, initBoobstrap } from "@boobstrap/boobstrap/js";
import type { AccordionProvider } from "@boobstrap/alpine";
import tokenArtifact, { modes, tokens } from "@boobstrap/boobstrap/tokens";

Use the TypeScript guide for compiler and import details, and the token reference for artifact structure and DTCG-compatible values.

Adapter parity

Accordion state is available as bsAccordion in Alpine and useAccordion in React and Vue. Toast autohide in React and Vue now pauses for pointer hover and keyboard focus, matching the vanilla and Alpine interaction contract. A machine-readable conformance manifest and adapter tests guard these capabilities from drifting.

JavaScript · Choose one state owner
// Vanilla progressive enhancement
import { initAccordions } from "@boobstrap/boobstrap/js/accordion";
const controllers = initAccordions(document);

// Or let one framework adapter own the subtree:
// Alpine: bsAccordion · React/Vue: useAccordion

Release confidence

The release gate now includes strict TypeScript fixtures, adapter conformance checks, distributable token verification, and Playwright visual baselines in addition to CSS, packaging, browser, and accessibility coverage. These checks protect the public surface that the guides describe.

Preview safely

Evaluate v0.5 through the dev integration pointer instead of publishing or depending on an interim registry build.

Remove workarounds

If application code supplied adapter-specific toast pause timers, remove that workaround and verify hover and focus timing.

Keep CSS canonical

Use CSS custom properties for runtime styling; consume token artifacts only where code or design tooling needs structured data.
